# Клинические протоколы МЗ РК

Один файл на протокол. Перечни обследований выписываются из официального текста
протокола и сверяются врачом. Пока врач не сверил, в файле стоит
`"verified_by_doctor": false`, и в интерфейсе блок помечен «черновик».

Подсказывается только диагностика. Диагноз и лечение остаются за врачом.

```json
{
  "title": "Название протокола",
  "version": "Клинические протоколы МЗ РК, 2016",
  "approved": "кем и когда одобрен, номер протокола",
  "source": "ссылка на текст",
  "icd": ["J03"],
  "verified_by_doctor": false,
  "sections": [
    {"key": "labs", "title": "Лабораторные исследования", "items": [
      {"text": "ОАК", "keywords": ["анализ крови", "оак"], "note": "по показаниям"}
    ]}
  ]
}
```

`keywords` нужны, чтобы понять, есть ли пункт уже в листе. Слова короче четырёх
букв ищутся целиком, остальные как начало слова.

Если протокол расписан по срокам беременности, вместо `sections` задаются `visits`:
у каждого посещения `weeks` (с какой по какую неделю его показывать), `official`
(срок из протокола) и свои `sections`. Посещение выбирается по сроку, который
система считает из даты последней менструации.

Сейчас подключены:

| Файл | Протокол | Коды |
|---|---|---|
| antenatal_care_2025.json | Антенатальный уход, 2025 (одобрен 17.03.2026, №248) | Z34, Z32.1, Z33, Z35, Z36 |
| tonsillitis_2016.json | Острый и хронический тонзиллит, 2016 (№5 от 23.06.2016) | J03, J35.0 |
| chronic_cholecystitis_2013.json | Хронический холецистит, 2013 (№23 от 12.12.2013) | K81.1 |

Тексты взяты со справочной системы MedElement, где размещены протоколы МЗ РК.
Протокол «Ведение физиологической беременности» 2013 года утратил силу, вместо него
действует «Антенатальный уход».

## Загрузчик

`scripts/import_protocol.py <ссылка на протокол в MedElement>` сам вырезает раздел
диагностики амбулаторного уровня и сохраняет файл-черновик. На протоколе по тонзиллиту
(формат 2016 года) он дал тот же перечень, что выписан вручную. На протоколе «Грипп и ОРВИ
у взрослых» 2024 года перечень не нашёл: у новых протоколов другая разметка, под неё
загрузчик нужно дорабатывать. Ключ `--show` показывает результат без сохранения.
